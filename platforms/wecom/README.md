# 企业微信参考资料

企业微信官方任务管理相关功能索引。核实于 2026-11-03。

## 官方功能

以下为官方开放能力清单（从企业微信官网核实）：

| 功能 | 说明 |
|------|------|
| 待办 | 创建待办、编辑待办、完成待办、检索待办、读取待办详情 |
| 日程 | 新建日程、编辑日程、检索日程、读取日程详情 |
| 会议 | 新建会议、编辑会议、检索会议、读取会议详情和纪要 |
| 文档 / 表格 / 智能表格 / 智能文档 | 创建、检索、读取、编辑 |

OKR：官方开放能力清单未列 OKR 功能（同页核实）。
